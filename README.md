# KOINONIA

**Conhecimento que edifica. Verdade que transforma.**

Plataforma de livros e conhecimento cristão, com lançamento inicial como livraria digital para o público angolano.

## Stack actual
- Vite 6
- JavaScript puro (Vanilla JavaScript)
- HTML5
- CSS responsivo

A aplicação não utiliza React nem outras bibliotecas de interface.

## Desenvolvimento local
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Estado actual
A landing page apresenta a marca Koinonia, categorias temáticas, secção institucional e chamada para a futura biblioteca digital.
